# Επεξήγηση Μοντέλων - Part 1: Fashion-MNIST & CIFAR-10

## Γενικό Πλαίσιο

Στο πρώτο μέρος του project δουλέψαμε με δύο γνωστά datasets εικόνων:

- **Fashion-MNIST**: 70.000 γκρι εικόνες 28x28 pixels με ρούχα (10 κατηγορίες). Σχετικά εύκολο dataset — οι εικόνες είναι καθαρές, κεντραρισμένες και μικρές.
- **CIFAR-10**: 60.000 έγχρωμες εικόνες 32x32 pixels με αντικείμενα πραγματικού κόσμου (αυτοκίνητα, πουλιά, γάτες κλπ). Πολύ πιο δύσκολο — διαφορετικά background, γωνίες και φωτισμός.

Σκοπός: να δούμε πώς κάθε αρχιτεκτονική βελτιώνει την απόδοση, ξεκινώντας από το πιο απλό μοντέλο και φτάνοντας στο πιο πολύπλοκο.

### Κοινές Ρυθμίσεις για Όλα τα Μοντέλα

| Παράμετρος | Τιμή |
|---|---|
| Optimizer | Adam (lr = 0.001) |
| Loss | Sparse Categorical Crossentropy |
| Epochs | 20 (με EarlyStopping, patience=3) |
| Batch size | 64 |
| Normalization | Pixel values / 255 (εύρος 0-1) |
| Seed | 42 (για αναπαραγωγιμότητα) |

## Μοντέλο 1: MLP (Baseline)

### Τι είναι το MLP;

MLP σημαίνει **Multi-Layer Perceptron** — το πιο βασικό νευρωνικό δίκτυο που υπάρχει. Αποτελείται αποκλειστικά από Dense (πλήρως συνδεδεμένα) layers, χωρίς καμία ειδική επεξεργασία για εικόνες.

### Αρχιτεκτονική

```
Είσοδος: εικόνα 28x28 (ή 32x32x3)
    |
Flatten  →  μετατρέπει την εικόνα σε 1D διάνυσμα (784 ή 3072 αριθμοί)
    |
Dense(512) → BatchNormalization → ReLU → Dropout(0.3)
    |
Dense(256) → BatchNormalization → ReLU → Dropout(0.3)
    |
Dense(128) → BatchNormalization → ReLU → Dropout(0.3)
    |
Dense(10)  → Softmax  (10 κατηγορίες)
```

### Βασικές Έννοιες

**Flatten:** Παίρνει την εικόνα (π.χ. 28x28 = 784 pixels) και την "ξεδιπλώνει" σε μια μακριά σειρά αριθμών. Από αυτό το σημείο, το μοντέλο δεν ξέρει ποιοι pixels είναι γείτονες — χάνεται όλη η χωρική πληροφορία.

**Dense Layer:** Κάθε νευρώνας είναι συνδεδεμένος με ΟΛΟΥΣ τους νευρώνες της προηγούμενης στρώσης. Μαθαίνει γραμμικούς συνδυασμούς των εισόδων.

**BatchNormalization:** Κανονικοποιεί τις ενεργοποιήσεις κάθε layer ώστε να έχουν μέσο όρο 0 και τυπική απόκλιση 1. Βοηθάει στη σταθερή εκπαίδευση και επιτρέπει μεγαλύτερα learning rates.

**Dropout(0.3):** Κατά την εκπαίδευση, "σβήνει" τυχαία το 30% των νευρώνων σε κάθε βήμα. Αναγκάζει το δίκτυο να μάθει πλεονάζουσες αναπαραστάσεις και μειώνει το overfitting.

**ReLU:** Συνάρτηση ενεργοποίησης: f(x) = max(0, x). Απλή αλλά αποτελεσματική — εισάγει μη-γραμμικότητα στο δίκτυο.

**Softmax:** Στην έξοδο μετατρέπει τους αριθμούς σε πιθανότητες που αθροίζουν στο 1.

### Αποτελέσματα

| Dataset | Accuracy |
|---|---|
| Fashion-MNIST | 88.48% |
| CIFAR-10 | 50.72% |

### Γιατί τα αποτελέσματα είναι έτσι;

Στο Fashion-MNIST τα πάει καλά (88%) γιατί οι εικόνες είναι απλές και κεντραρισμένες. Το Flatten δεν καταστρέφει πολλή πληροφορία.

Στο CIFAR-10 όμως 50.72% είναι σχεδόν τυχαίο (10 κατηγορίες = 10% τυχαίο). Το να "ξεδιπλώσεις" μια έγχρωμη εικόνα 32x32x3 σε 3072 αριθμούς είναι καταστροφικό — το μοντέλο δεν μπορεί να αναγνωρίσει ότι ένα αντικείμενο είναι το ίδιο αν εμφανιστεί σε διαφορετική θέση.

## Μοντέλο 2: Simple CNN

### Τι είναι το CNN;

CNN σημαίνει **Convolutional Neural Network**. Αντί να "ξεδιπλώνει" την εικόνα, χρησιμοποιεί φίλτρα (kernels) που "σαρώνουν" την εικόνα και ανιχνεύουν τοπικά χαρακτηριστικά (ακμές, γωνίες, υφές).

### Αρχιτεκτονική

```
Είσοδος: εικόνα
    |
Conv2D(32, 3x3) → ReLU      ← ανιχνεύει απλά χαρακτηριστικά (ακμές)
MaxPooling(2x2)              ← μειώνει τις διαστάσεις στο μισό
    |
Conv2D(64, 3x3) → ReLU      ← ανιχνεύει πιο σύνθετα χαρακτηριστικά
MaxPooling(2x2)              ← μειώνει ξανά τις διαστάσεις
    |
Flatten
Dense(128) → ReLU → Dropout(0.4)
Dense(10)  → Softmax
```

### Βασικές Έννοιες

**Conv2D(32, 3x3):** 32 φίλτρα μεγέθους 3x3. Κάθε φίλτρο "σαρώνει" ολόκληρη την εικόνα και παράγει έναν feature map — μια "χάρτη" που δείχνει πού εντοπίστηκε το αντίστοιχο χαρακτηριστικό. Τα βάρη του φίλτρου είναι κοινά για όλες τις θέσεις (weight sharing) — αυτό σημαίνει ότι αν μάθει να ανιχνεύει μια ακμή κάπου, την ανιχνεύει παντού.

**MaxPooling(2x2):** Χωρίζει τον feature map σε τετράγωνα 2x2 και κρατάει μόνο τη μέγιστη τιμή από κάθε τετράγωνο. Αποτέλεσμα: μισές διαστάσεις, λιγότεροι υπολογισμοί, μικρή μετατόπιση δεν επηρεάζει το αποτέλεσμα (translational invariance).

### Γιατί το CNN είναι καλύτερο από το MLP;

- Διατηρεί τη χωρική δομή της εικόνας
- Weight sharing: πολύ λιγότερες παράμετροι από Dense layers
- Τοπικές συνδέσεις: κάθε νευρώνας βλέπει μόνο μια μικρή περιοχή
- Translation invariance: αναγνωρίζει αντικείμενα ανεξάρτητα από θέση

### Αποτελέσματα

| Dataset | Accuracy |
|---|---|
| Fashion-MNIST | 92.44% |
| CIFAR-10 | 71.66% |

Τεράστια βελτίωση στο CIFAR-10 (+21%) μόνο από το να χρησιμοποιήσουμε convolutions!

## Μοντέλο 3: Deep CNN (VGG-style)

### Τι αλλάζει;

Εμπνευσμένο από το **VGG** (Oxford, 2014): αντί για μία convolution ανά block, χρησιμοποιούμε **δύο συνεχόμενες convolutions** πριν από κάθε pooling. Επίσης βαθαίνουμε το δίκτυο με 3 blocks αντί για 2.

### Αρχιτεκτονική

```
Block 1: Conv2D(32) → BN → ReLU → Conv2D(32) → BN → ReLU → MaxPool → Dropout(0.2)
Block 2: Conv2D(64) → BN → ReLU → Conv2D(64) → BN → ReLU → MaxPool → Dropout(0.3)
Block 3: Conv2D(128)→ BN → ReLU → Conv2D(128)→ BN → ReLU → MaxPool → Dropout(0.4)
    |
Flatten → Dense(256) → BN → ReLU → Dropout(0.5) → Dense(10) → Softmax
```

### Γιατί διπλές convolutions;

Δύο συνεχόμενα Conv(3x3) έχουν το ίδιο receptive field με ένα Conv(5x5), αλλά με λιγότερες παραμέτρους και μία επιπλέον μη-γραμμικότητα (ReLU). Αυτό επιτρέπει στο δίκτυο να μάθει πιο σύνθετα χαρακτηριστικά σε κάθε επίπεδο χωρικής ανάλυσης πριν κάνει downsampling.

**Progressive Dropout (0.2 → 0.3 → 0.4):** Αυξάνουμε το dropout σε κάθε block γιατί τα βαθύτερα layers έχουν πιο αφηρημένες αναπαραστάσεις που είναι πιο ευάλωτες στο overfitting.

### Αποτελέσματα

| Dataset | Accuracy |
|---|---|
| Fashion-MNIST | 93.14% |
| CIFAR-10 | 83.94% |

Η μεγαλύτερη άλμα στο CIFAR-10: +12.28% από το Simple CNN!

## Μοντέλο 4: Deep CNN v2

### Τι αλλάζει;

Δύο βελτιώσεις πάνω στο Deep CNN:
1. **Διπλασιασμός φίλτρων**: 32→64→128 γίνεται 64→128→256
2. **GlobalAveragePooling αντί για Flatten**

### Αρχιτεκτονική

```
Block 1: Conv2D(64)  → BN → ReLU → Conv2D(64)  → BN → ReLU → MaxPool → Dropout(0.2)
Block 2: Conv2D(128) → BN → ReLU → Conv2D(128) → BN → ReLU → MaxPool → Dropout(0.3)
Block 3: Conv2D(256) → BN → ReLU → Conv2D(256) → BN → ReLU → MaxPool → Dropout(0.4)
    |
GlobalAveragePooling2D      ← αντί για Flatten!
Dense(256) → BN → ReLU → Dropout(0.5) → Dense(10) → Softmax
```

### GlobalAveragePooling vs Flatten

Αυτή είναι η πιο σημαντική αλλαγή:

**Flatten:** Αν ο τελευταίος feature map είναι 4x4x256, το Flatten τον κάνει 4096 αριθμούς. Το Dense layer μετά έχει 4096 × 256 = ~1 εκατομμύριο παραμέτρους μόνο σε αυτό το layer. Τεράστιος κίνδυνος overfitting.

**GlobalAveragePooling (GAP):** Παίρνει κάθε feature map 4x4 και τον κάνει έναν μόνο αριθμό (τον μέσο όρο). Άρα 256 feature maps → 256 αριθμοί. Το Dense layer μετά έχει μόνο 256 × 256 = 65.536 παραμέτρους. Δραματική μείωση overfitting!

**Conv → BN → ReLU pattern:** Στο Deep CNN v2 τοποθετούμε το BatchNorm ΠΡΙΝ από το ReLU (αντί για μετά). Αυτή είναι η "σωστή" σειρά σύμφωνα με αρκετές ερευνητικές εργασίες — το BN κανονικοποιεί πριν η ενεργοποίηση "κόψει" αρνητικές τιμές.

### Αποτελέσματα

| Dataset | Accuracy |
|---|---|
| Fashion-MNIST | 94.35% |
| CIFAR-10 | 89.32% |

+5.38% στο CIFAR-10 κυρίως από το GAP!

## Μοντέλο 5: CNN με Data Augmentation

### Τι είναι το Data Augmentation;

Αντί να δείχνουμε στο μοντέλο πάντα την ίδια εικόνα, τη μεταμορφώνουμε λίγο κάθε φορά κατά την εκπαίδευση. Έτσι το μοντέλο "βλέπει" ουσιαστικά περισσότερα δεδομένα και μαθαίνει να είναι ανθεκτικό σε μικρές αλλαγές.

### Αρχιτεκτονική

Ίδια με το Deep CNN v2, με ένα επιπλέον augmentation block στην αρχή:

```
Είσοδος
    |
RandomFlip("horizontal")    ← αναστρέφει οριζόντια με πιθανότητα 50%
RandomRotation(0.05)        ← περιστρέφει έως ±5%  (±18 μοίρες)
RandomZoom(0.05)            ← zoom έως ±5%
    |
[ίδια αρχιτεκτονική με Deep CNN v2]
```

### Βασικά Σημεία

- Οι μεταμορφώσεις γίνονται **μόνο κατά την εκπαίδευση** — κατά την αξιολόγηση χρησιμοποιείται η αρχική εικόνα
- Κρατήσαμε τις μεταμορφώσεις **ήπιες** (5%) ώστε να μην αλλοιώσουμε υπερβολικά τα αντικείμενα
- Το augmentation είναι ενσωματωμένο στο μοντέλο (όχι στο pipeline δεδομένων)

### Αποτελέσματα

| Dataset | Accuracy |
|---|---|
| Fashion-MNIST | 94.19% |
| CIFAR-10 | 88.44% |

Ελαφρώς χαμηλότερο accuracy από το Deep CNN v2, αλλά **χαμηλότερο test loss** (0.37 vs 0.47). Αυτό σημαίνει ότι το μοντέλο είναι πιο καλά βαθμονομημένο — όταν κάνει λάθος, είναι λιγότερο σίγουρο για αυτό. Πρακτικά πιο χρήσιμο!

## Μοντέλο 6: ResNet from Scratch

### Τι είναι το ResNet;

Το **ResNet (Residual Network)** εισήχθη από Microsoft Research το 2015 και κέρδισε το ImageNet competition εκείνη τη χρονιά. Η βασική ιδέα είναι οι **skip connections** (ή residual connections): η έξοδος κάθε block προστίθεται με την είσοδό του.

### Το Πρόβλημα που Λύνει

Καθώς προσθέτουμε περισσότερα layers, τα gradients που backpropagation στέλνει πίσω γίνονται ολοένα και μικρότερα. Στα πρώτα layers τα gradients είναι σχεδόν μηδέν — δεν μαθαίνουν τίποτα. Αυτό ονομάζεται **vanishing gradient problem**.

### Η Λύση: Skip Connections

```
        x (είσοδος)
       / \
      /   \
  F(x)    |    ← το block μαθαίνει μόνο το "υπόλοιπο" (residual)
      \   /
       \ /
    F(x) + x   ← πρόσθεση με shortcut
```

Αντί να μάθει απευθείας μια μεταμόρφωση H(x), το block μαθαίνει το F(x) = H(x) - x (δηλαδή την "διαφορά" από την ταυτότητα). Αν η βέλτιστη μεταμόρφωση είναι κοντά στην ταυτότητα, το F(x) ≈ 0, που είναι πολύ εύκολο να μάθει το δίκτυο.

Επίσης, τα gradients μπορούν να ρέουν απευθείας μέσω της skip connection χωρίς να περνούν από τα βάρη — λύνει το vanishing gradient!

### Αρχιτεκτονική

```
Είσοδος
    |
Conv2D(64, 3x3) → BN → ReLU → MaxPool    ← stem block
    |
Residual Block (64 filters)
Residual Block (64 filters)
    |
MaxPool(2x2)
    |
Residual Block (128 filters)    ← shortcut: Conv1x1 για αλλαγή διαστάσεων
Residual Block (128 filters)
    |
GlobalAveragePooling
Dense(10) → Softmax
```

### Residual Block σε Detail

```python
# Κάθε Residual Block:
shortcut = x                          # κρατάμε την είσοδο

x = Conv2D(filters, 3x3) → BN → ReLU
x = Conv2D(filters, 3x3) → BN        # χωρίς ReLU πριν το add!

# Αν αλλάζουν τα filters, προσαρμόζουμε το shortcut:
if filters_changed:
    shortcut = Conv2D(filters, 1x1) → BN   # 1x1 conv για αλλαγή διαστάσεων

output = x + shortcut                 # η κρίσιμη πρόσθεση
output = ReLU(output)                 # ReLU μετά το add
```

### Γιατί 1x1 Convolution στο Shortcut;

Όταν αλλάζουμε τον αριθμό των filters (π.χ. από 64 σε 128), δεν μπορούμε να προσθέσουμε απευθείας γιατί οι διαστάσεις δεν ταιριάζουν. Ένα Conv2D(1x1) αλλάζει μόνο τον αριθμό των channels χωρίς να επεξεργαστεί τη χωρική δομή.

### Αποτελέσματα

| Dataset | Accuracy |
|---|---|
| Fashion-MNIST | **94.49%** |
| CIFAR-10 | **89.40%** |

Καλύτερο συνολικά, αλλά με πολύ μικρή διαφορά από το Deep CNN v2 (0.08% στο CIFAR-10). Το ResNet έδειξε πιο σταθερή εκπαίδευση και λιγότερες διακυμάνσεις στις καμπύλες μάθησης.

## Ανάλυση: Τι Έμαθε Κάθε Βελτίωση;

### Fashion-MNIST — Γιατί όλα τα μοντέλα τα πάνε καλά;
Το dataset είναι πολύ καθαρό. Ακόμα και το MLP (88%) αποδίδει αξιοπρεπώς. Η διαφορά μεταξύ μοντέλων είναι μικρή (88%–94%) γιατί δεν χρειάζεται μεγάλη εκφραστικότητα.

### CIFAR-10 — Εδώ φαίνεται η αρχιτεκτονική
- MLP → Simple CNN: **+21%** (το μεγαλύτερο άλμα — convolutions λύνουν το βασικό πρόβλημα)
- Simple CNN → Deep CNN: **+12%** (βάθος + διπλές convolutions)
- Deep CNN → Deep CNN v2: **+5.4%** (GlobalAveragePooling)
- Deep CNN v2 → ResNet: **+0.1%** (skip connections βοηθούν κυρίως στη σταθερότητα)

### Data Augmentation — Η Έκπληξη
Η augmentation έδωσε χαμηλότερο accuracy (88.44% vs 89.32%) αλλά **χαμηλότερο loss**. Αυτό λέει ότι το μοντέλο κάνει καλύτερες εκτιμήσεις πιθανότητας — δεν είναι υπερβολικά σίγουρο όταν κάνει λάθος. Σε real-world εφαρμογές αυτό είναι συχνά πιο σημαντικό από το raw accuracy.

## Τι να Πεις στην Παρουσίαση

### Για το MLP
> "Ξεκινήσαμε με το πιο απλό μοντέλο. Το MLP δεν ξέρει τίποτα για εικόνες — απλά βλέπει μια λίστα από αριθμούς. Γι' αυτό στο CIFAR-10 τα πάει χάλια (50%), σχεδόν τυχαία."

### Για το CNN
> "Μόλις προσθέσαμε convolutions, το CIFAR-10 πήγε στο 71%. Τα CNN 'καταλαβαίνουν' ότι η εικόνα έχει χωρική δομή — γνωρίζουν ποιοι pixels είναι γείτονες."

### Για το Deep CNN / v2
> "Πηγαίνοντας βαθύτερα και χρησιμοποιώντας GlobalAveragePooling αντί για Flatten, φτάσαμε στο 89%. Το GAP μειώνει δραστικά τις παραμέτρους και το overfitting."

### Για το ResNet
> "Το ResNet λύνει ένα πρόβλημα που εμφανίζεται στα βαθιά δίκτυα: τα gradients 'εξαφανίζονται' πριν φτάσουν στα πρώτα layers. Οι skip connections δίνουν στα gradients μια 'shortcut' για να ρέουν απευθείας."

### Γενικό Συμπέρασμα
> "Κάθε αρχιτεκτονική βελτίωση είχε ξεκάθαρη αιτιολόγηση και μετρήσιμο αντίκτυπο. Το πιο σημαντικό μάθημα: για εικόνες, η αρχιτεκτονική μετράει πολύ περισσότερο από τις hyperparameters."
